# Holberton School – DevOps Formation

This repository contains projects completed as part of the DevOps formation
at Holberton School (Rennes campus), bachelor "Agentic IA Fullstack".

## Projects

| Project | Description |
|---|---|
| [devops_culture_git](./devops_culture_git) | DevOps culture fundamentals: CALMS, DORA metrics, GitHub Flow, conventional commits, merge conflict resolution, blameless post-mortems. |
| [docker_fundamentals](./docker_fundamentals) | Docker basics: running and exploring containers, writing a first Dockerfile, debugging a broken image. |
